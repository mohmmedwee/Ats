# GulfCart — Database Schema (PostgreSQL 17)

This is the reference schema. Laravel migrations are the source of truth once they exist;
keep this document in sync. Corrections made to the v1.0 draft are listed in
[`SPEC_REVIEW.md`](SPEC_REVIEW.md#database).

## 1. Design principles

- UUID primary keys (ordered UUIDs generated by the application, `gen_random_uuid()` as DB default).
- `NUMERIC` for money: `NUMERIC(14,2)` for customer amounts, `NUMERIC(14,4)` for costs,
  `NUMERIC(18,8)` for FX rates. Never floating point.
- ISO 4217 currencies (`CHAR(3)`), ISO 3166-1 alpha-2 countries (`CHAR(2)`).
- All timestamps `TIMESTAMPTZ` in UTC, `created_at` and `updated_at` on mutable tables.
- Status columns are `VARCHAR` with a `CHECK` constraint listing allowed values.
- Foreign keys on every important relation; indexes on every FK and lookup column.
- Soft deletes (`deleted_at`) only on catalog and supplier configuration, never on financial rows.
- `JSONB` only for variable or supplier-specific data and for translatable text.
- Financial rows for completed orders are immutable (enforced by application and by a
  trigger that rejects `UPDATE` of amount columns).
- Roles and permissions use the `spatie/laravel-permission` tables (`roles`, `permissions`,
  `model_has_roles`, `model_has_permissions`, `role_has_permissions`), with UUID morph keys.

## 2. Core schema

```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS citext;

-- ===== Countries & identity =====
CREATE TABLE countries (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code CHAR(2) NOT NULL UNIQUE,
    name JSONB NOT NULL,                       -- {"en":"United Arab Emirates","ar":"…"}
    currency_code CHAR(3) NOT NULL,
    default_locale VARCHAR(10) NOT NULL,       -- ar-AE
    supported_locales VARCHAR(10)[] NOT NULL,  -- {ar-AE,en-AE}
    timezone VARCHAR(64) NOT NULL,             -- Asia/Dubai
    settings JSONB NOT NULL DEFAULT '{}',      -- rounding rule, phone format, return window…
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(150) NOT NULL,
    email CITEXT UNIQUE,
    phone VARCHAR(30) UNIQUE,                  -- E.164
    password VARCHAR(255),
    type VARCHAR(20) NOT NULL DEFAULT 'customer' CHECK (type IN ('customer','staff')),
    status VARCHAR(30) NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended','closed')),
    preferred_locale VARCHAR(10),
    email_verified_at TIMESTAMPTZ,
    phone_verified_at TIMESTAMPTZ,
    mfa_secret TEXT,                           -- encrypted cast
    mfa_confirmed_at TIMESTAMPTZ,
    last_login_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CHECK (email IS NOT NULL OR phone IS NOT NULL)
);
-- Roles/permissions: spatie/laravel-permission tables.

CREATE TABLE customer_addresses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    full_name VARCHAR(150) NOT NULL,
    phone VARCHAR(30) NOT NULL,
    address_line_1 VARCHAR(255) NOT NULL,
    address_line_2 VARCHAR(255),
    district VARCHAR(100),
    city VARCHAR(100) NOT NULL,
    state VARCHAR(100),                        -- emirate / region
    postal_code VARCHAR(30),
    national_address_code VARCHAR(20),         -- SA short address, optional
    is_default BOOLEAN NOT NULL DEFAULT FALSE,
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE UNIQUE INDEX uq_default_address ON customer_addresses(user_id)
    WHERE is_default AND deleted_at IS NULL;

-- ===== Suppliers =====
CREATE TABLE suppliers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(150) NOT NULL,
    code VARCHAR(50) NOT NULL UNIQUE,
    connector_type VARCHAR(50) NOT NULL,       -- mock | manual | <authorized connector key>
    base_currency CHAR(3) NOT NULL,
    api_base_url TEXT,
    credentials_ref TEXT,                      -- reference to secret store, never the secret
    commercial_authorization_status VARCHAR(30) NOT NULL DEFAULT 'pending'
        CHECK (commercial_authorization_status IN ('pending','approved','suspended','revoked')),
    direct_shipping_enabled BOOLEAN NOT NULL DEFAULT FALSE,
    is_active BOOLEAN NOT NULL DEFAULT FALSE,
    metadata JSONB NOT NULL DEFAULT '{}',
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CHECK (NOT is_active OR commercial_authorization_status = 'approved')
);

CREATE TABLE supplier_authorizations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_id UUID NOT NULL REFERENCES suppliers(id),
    agreement_reference VARCHAR(255) NOT NULL,
    allows_resale BOOLEAN NOT NULL,
    allows_api_purchasing BOOLEAN NOT NULL,
    allows_direct_shipping BOOLEAN NOT NULL,
    allows_image_use BOOLEAN NOT NULL,
    countries CHAR(2)[] NOT NULL,
    document_path TEXT,                        -- private S3 object
    valid_from DATE NOT NULL,
    valid_until DATE,
    approved_by UUID REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- ===== Catalog =====
CREATE TABLE categories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    parent_id UUID REFERENCES categories(id),
    name JSONB NOT NULL,
    slug VARCHAR(180) NOT NULL UNIQUE,
    sort_order INTEGER NOT NULL DEFAULT 0,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE products (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    category_id UUID REFERENCES categories(id),
    title JSONB NOT NULL,
    slug VARCHAR(255) NOT NULL UNIQUE,
    description JSONB,
    status VARCHAR(30) NOT NULL DEFAULT 'draft'
        CHECK (status IN ('draft','pending_review','published','unpublished','archived')),
    brand VARCHAR(150),
    attributes JSONB NOT NULL DEFAULT '{}',
    weight_grams INTEGER,
    hs_code VARCHAR(20),                       -- customs classification
    country_of_origin CHAR(2),
    published_at TIMESTAMPTZ,
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE product_variants (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    product_id UUID NOT NULL REFERENCES products(id),
    sku VARCHAR(100) NOT NULL UNIQUE,
    attributes JSONB NOT NULL DEFAULT '{}',    -- {"size":"M","color":"Black"}
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE product_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    product_id UUID NOT NULL REFERENCES products(id),
    variant_id UUID REFERENCES product_variants(id),
    storage_path TEXT NOT NULL,                -- copied to our storage; never hotlinked
    source_url TEXT,
    rights_status VARCHAR(30) NOT NULL DEFAULT 'pending'
        CHECK (rights_status IN ('pending','approved','rejected')),
    rights_basis VARCHAR(100),                 -- supplier_agreement | own_photo | licensed
    alt_text JSONB,
    sort_order INTEGER NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE product_country_availability (
    product_id UUID NOT NULL REFERENCES products(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    is_available BOOLEAN NOT NULL DEFAULT TRUE,
    estimated_delivery_min_days SMALLINT,
    estimated_delivery_max_days SMALLINT,
    restriction_reason VARCHAR(255),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    PRIMARY KEY (product_id, country_id)
);

CREATE TABLE supplier_products (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_id UUID NOT NULL REFERENCES suppliers(id),
    product_id UUID NOT NULL REFERENCES products(id),
    external_product_id VARCHAR(255) NOT NULL,
    external_sku VARCHAR(255),
    source_url TEXT,
    cost_price NUMERIC(14,4) NOT NULL CHECK (cost_price >= 0),
    cost_currency CHAR(3) NOT NULL,
    stock_status VARCHAR(30) NOT NULL CHECK (stock_status IN ('in_stock','low_stock','out_of_stock','unknown')),
    priority SMALLINT NOT NULL DEFAULT 100,    -- lower = preferred source
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    supplier_data JSONB NOT NULL DEFAULT '{}',
    last_synced_at TIMESTAMPTZ,
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (supplier_id, external_product_id)
);

CREATE TABLE supplier_variant_mappings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_product_id UUID NOT NULL REFERENCES supplier_products(id),
    variant_id UUID NOT NULL REFERENCES product_variants(id),
    external_variant_id VARCHAR(255) NOT NULL,
    cost_price NUMERIC(14,4),                  -- overrides supplier_products.cost_price
    stock_status VARCHAR(30),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (supplier_product_id, variant_id),
    UNIQUE (supplier_product_id, external_variant_id)
);

-- ===== Pricing =====
CREATE TABLE exchange_rates (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    base_currency CHAR(3) NOT NULL,
    target_currency CHAR(3) NOT NULL,
    rate NUMERIC(18,8) NOT NULL CHECK (rate > 0),
    source VARCHAR(100) NOT NULL,
    effective_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (base_currency, target_currency, effective_at)
);

CREATE TABLE pricing_rules (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    scope VARCHAR(20) NOT NULL CHECK (scope IN ('global','country','supplier','category','product')),
    country_id UUID REFERENCES countries(id),
    supplier_id UUID REFERENCES suppliers(id),
    category_id UUID REFERENCES categories(id),
    product_id UUID REFERENCES products(id),
    rule_type VARCHAR(20) NOT NULL CHECK (rule_type IN ('margin_percent','markup_percent','fixed_markup')),
    value NUMERIC(12,4) NOT NULL,
    min_margin_percent NUMERIC(8,4),
    max_selling_price NUMERIC(14,2),
    priority INTEGER NOT NULL DEFAULT 100,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    starts_at TIMESTAMPTZ,
    ends_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Current published price per variant and country (one row), computed by the pricing engine.
CREATE TABLE product_prices (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    variant_id UUID NOT NULL REFERENCES product_variants(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    supplier_product_id UUID NOT NULL REFERENCES supplier_products(id), -- source used to price
    gross_price NUMERIC(14,2) NOT NULL,        -- VAT inclusive, shown to customer
    net_price NUMERIC(14,2) NOT NULL,
    currency CHAR(3) NOT NULL,
    variable_cost NUMERIC(14,4) NOT NULL,
    exchange_rate_id UUID REFERENCES exchange_rates(id),
    calculation JSONB NOT NULL,                -- full engine output for audit
    valid_until TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (variant_id, country_id)
);

-- ===== Tax, customs, shipping =====
CREATE TABLE tax_rules (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    country_id UUID NOT NULL REFERENCES countries(id),
    tax_type VARCHAR(30) NOT NULL CHECK (tax_type IN ('vat','import_vat')),
    category_id UUID REFERENCES categories(id),  -- NULL = default for country
    rate_percent NUMERIC(8,4) NOT NULL,
    is_recoverable BOOLEAN NOT NULL DEFAULT FALSE,
    applies_to_shipping BOOLEAN NOT NULL DEFAULT TRUE,
    effective_from DATE NOT NULL,
    effective_to DATE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE customs_rules (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    country_id UUID NOT NULL REFERENCES countries(id),
    hs_code_prefix VARCHAR(20),                -- NULL = default
    duty_percent NUMERIC(8,4) NOT NULL,
    valuation_basis VARCHAR(10) NOT NULL DEFAULT 'CIF' CHECK (valuation_basis IN ('CIF','FOB')),
    de_minimis_amount NUMERIC(14,2),
    de_minimis_currency CHAR(3),
    shipping_mode VARCHAR(30),                 -- courier | postal | cargo
    effective_from DATE NOT NULL,
    effective_to DATE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE shipping_methods (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    country_id UUID NOT NULL REFERENCES countries(id),
    code VARCHAR(50) NOT NULL,                 -- standard | express
    name JSONB NOT NULL,
    carrier VARCHAR(100),
    pricing_model VARCHAR(30) NOT NULL CHECK (pricing_model IN ('flat','weight_band','supplier_quote','carrier_api')),
    config JSONB NOT NULL DEFAULT '{}',
    free_shipping_threshold NUMERIC(14,2),
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (country_id, code)
);

-- ===== Cart & checkout =====
CREATE TABLE carts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id),
    guest_token VARCHAR(64) UNIQUE,
    country_id UUID NOT NULL REFERENCES countries(id),
    currency CHAR(3) NOT NULL,
    status VARCHAR(30) NOT NULL DEFAULT 'active' CHECK (status IN ('active','converted','abandoned','merged')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CHECK (user_id IS NOT NULL OR guest_token IS NOT NULL)
);
CREATE UNIQUE INDEX uq_active_cart_user ON carts(user_id, country_id) WHERE status = 'active';

CREATE TABLE cart_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    cart_id UUID NOT NULL REFERENCES carts(id) ON DELETE CASCADE,
    variant_id UUID NOT NULL REFERENCES product_variants(id),
    quantity INTEGER NOT NULL CHECK (quantity > 0 AND quantity <= 20),
    price_at_add NUMERIC(14,2) NOT NULL,       -- for price-change notice only
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (cart_id, variant_id)
);

CREATE TABLE checkout_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    cart_id UUID NOT NULL REFERENCES carts(id),
    user_id UUID NOT NULL REFERENCES users(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    address_id UUID REFERENCES customer_addresses(id),
    shipping_method_id UUID REFERENCES shipping_methods(id),
    currency CHAR(3) NOT NULL,
    quote JSONB NOT NULL,                      -- full locked quote incl. per-item breakdown
    subtotal NUMERIC(14,2) NOT NULL,
    shipping_total NUMERIC(14,2) NOT NULL,
    tax_total NUMERIC(14,2) NOT NULL,
    customs_total NUMERIC(14,2) NOT NULL,
    discount_total NUMERIC(14,2) NOT NULL,
    grand_total NUMERIC(14,2) NOT NULL,
    status VARCHAR(30) NOT NULL DEFAULT 'open' CHECK (status IN ('open','completed','expired','cancelled')),
    expires_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- ===== Orders =====
CREATE TABLE orders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_number VARCHAR(50) NOT NULL UNIQUE,  -- GC-10001
    user_id UUID NOT NULL REFERENCES users(id),
    checkout_session_id UUID UNIQUE REFERENCES checkout_sessions(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    address_id UUID REFERENCES customer_addresses(id),
    shipping_address_snapshot JSONB NOT NULL,  -- immutable copy
    currency CHAR(3) NOT NULL,
    locale VARCHAR(10) NOT NULL,
    status VARCHAR(40) NOT NULL CHECK (status IN (
        'pending_payment','payment_failed','expired','paid','processing',
        'partially_shipped','shipped','delivered','completed',
        'cancelled','partially_refunded','refunded')),
    subtotal NUMERIC(14,2) NOT NULL,
    shipping_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    tax_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    customs_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    discount_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    grand_total NUMERIC(14,2) NOT NULL,
    paid_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    refunded_total NUMERIC(14,2) NOT NULL DEFAULT 0,
    placed_at TIMESTAMPTZ,
    paid_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CHECK (grand_total = subtotal + shipping_total + tax_total + customs_total - discount_total),
    CHECK (refunded_total <= paid_total)
);

CREATE TABLE order_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID NOT NULL REFERENCES orders(id),
    product_id UUID REFERENCES products(id),
    variant_id UUID REFERENCES product_variants(id),
    supplier_product_id UUID NOT NULL REFERENCES supplier_products(id),
    product_snapshot JSONB NOT NULL,           -- title, attributes, image, sku
    quantity INTEGER NOT NULL CHECK (quantity > 0),
    unit_gross_price NUMERIC(14,2) NOT NULL,
    unit_net_price NUMERIC(14,2) NOT NULL,
    unit_tax NUMERIC(14,2) NOT NULL,
    line_total NUMERIC(14,2) NOT NULL,
    unit_supplier_cost NUMERIC(14,4) NOT NULL,
    supplier_currency CHAR(3) NOT NULL,
    exchange_rate_id UUID REFERENCES exchange_rates(id),
    exchange_rate NUMERIC(18,8) NOT NULL,
    pricing_snapshot JSONB NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- ===== Supplier orders & procurement =====
CREATE TABLE supplier_orders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    reference VARCHAR(50) NOT NULL UNIQUE,     -- SO-10001
    order_id UUID NOT NULL REFERENCES orders(id),
    supplier_id UUID NOT NULL REFERENCES suppliers(id),
    external_order_id VARCHAR(255),
    status VARCHAR(40) NOT NULL CHECK (status IN (
        'pending','procurement_pending','submitting','unknown','purchased',
        'supplier_processing','shipped','delivered','failed','exception',
        'cancel_requested','cancelled')),
    idempotency_key VARCHAR(255) NOT NULL UNIQUE,
    procurement_mode VARCHAR(20) NOT NULL DEFAULT 'automated' CHECK (procurement_mode IN ('automated','manual')),
    expected_cost NUMERIC(14,4) NOT NULL,
    actual_cost NUMERIC(14,4),
    cost_currency CHAR(3) NOT NULL,
    exchange_rate NUMERIC(18,8),
    supplier_response JSONB NOT NULL DEFAULT '{}',
    purchased_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (order_id, supplier_id),
    UNIQUE (supplier_id, external_order_id)
);

CREATE TABLE supplier_order_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_order_id UUID NOT NULL REFERENCES supplier_orders(id),
    order_item_id UUID NOT NULL REFERENCES order_items(id),
    external_variant_id VARCHAR(255) NOT NULL,
    purchase_quantity INTEGER NOT NULL CHECK (purchase_quantity > 0),
    purchase_cost NUMERIC(14,4) NOT NULL,
    currency CHAR(3) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (supplier_order_id, order_item_id)
);

CREATE TABLE procurement_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_order_id UUID NOT NULL UNIQUE REFERENCES supplier_orders(id),
    status VARCHAR(40) NOT NULL CHECK (status IN ('queued','in_progress','waiting_retry','reconciling','succeeded','exception','cancelled')),
    attempts INTEGER NOT NULL DEFAULT 0,
    next_attempt_at TIMESTAMPTZ,
    last_error JSONB,
    locked_at TIMESTAMPTZ,
    locked_by VARCHAR(100),
    assigned_to UUID REFERENCES users(id),     -- manual procurement / exception owner
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE procurement_attempts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    procurement_task_id UUID NOT NULL REFERENCES procurement_tasks(id),
    attempt_number INTEGER NOT NULL,
    action VARCHAR(30) NOT NULL,               -- revalidate | submit | reconcile | manual
    outcome VARCHAR(30) NOT NULL,              -- accepted | rejected | unknown | error
    error_class VARCHAR(30),                   -- safe_retry | unsafe | permanent
    request_payload JSONB,                     -- redacted
    response_payload JSONB,                    -- redacted
    duration_ms INTEGER,
    performed_by UUID REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (procurement_task_id, attempt_number)
);

-- ===== Payments & refunds =====
CREATE TABLE payments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID NOT NULL REFERENCES orders(id),
    provider VARCHAR(50) NOT NULL,
    provider_reference VARCHAR(255),
    idempotency_key VARCHAR(255) NOT NULL UNIQUE,
    amount NUMERIC(14,2) NOT NULL CHECK (amount > 0),
    currency CHAR(3) NOT NULL,
    status VARCHAR(30) NOT NULL CHECK (status IN ('created','requires_action','authorized','captured','failed','cancelled','refunded','partially_refunded')),
    refunded_amount NUMERIC(14,2) NOT NULL DEFAULT 0,
    method VARCHAR(30),                        -- card | apple_pay | mada | …
    failure_code VARCHAR(100),
    paid_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (provider, provider_reference),
    CHECK (refunded_amount <= amount)
);

CREATE TABLE payment_webhook_events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    provider VARCHAR(50) NOT NULL,
    provider_event_id VARCHAR(255) NOT NULL,
    event_type VARCHAR(100) NOT NULL,
    payload JSONB NOT NULL,
    signature_valid BOOLEAN NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'received' CHECK (status IN ('received','processed','ignored','failed')),
    processed_at TIMESTAMPTZ,
    error TEXT,
    received_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (provider, provider_event_id)
);

CREATE TABLE refunds (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID NOT NULL REFERENCES orders(id),
    payment_id UUID NOT NULL REFERENCES payments(id),
    return_id UUID,                            -- FK added with returns table
    amount NUMERIC(14,2) NOT NULL CHECK (amount > 0),
    currency CHAR(3) NOT NULL,
    reason_code VARCHAR(50) NOT NULL,          -- procurement_failed | customer_return | cancellation | goodwill
    reason TEXT,
    status VARCHAR(30) NOT NULL CHECK (status IN ('requested','approved','processing','succeeded','failed','rejected')),
    idempotency_key VARCHAR(255) NOT NULL UNIQUE,
    provider_reference VARCHAR(255),
    requested_by UUID REFERENCES users(id),
    approved_by UUID REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- ===== Shipping =====
CREATE TABLE shipments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_order_id UUID NOT NULL REFERENCES supplier_orders(id),
    carrier VARCHAR(100),
    tracking_number VARCHAR(255),
    tracking_url TEXT,
    status VARCHAR(40) NOT NULL CHECK (status IN ('pending','label_created','in_transit','customs','out_for_delivery','delivered','exception','returned')),
    shipped_at TIMESTAMPTZ,
    delivered_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (carrier, tracking_number)
);

CREATE TABLE shipment_items (
    shipment_id UUID NOT NULL REFERENCES shipments(id),
    supplier_order_item_id UUID NOT NULL REFERENCES supplier_order_items(id),
    quantity INTEGER NOT NULL CHECK (quantity > 0),
    PRIMARY KEY (shipment_id, supplier_order_item_id)
);

CREATE TABLE shipment_events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    shipment_id UUID NOT NULL REFERENCES shipments(id),
    event_code VARCHAR(100) NOT NULL,
    description TEXT,
    event_location VARCHAR(255),
    occurred_at TIMESTAMPTZ NOT NULL,
    raw JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (shipment_id, event_code, occurred_at)
);

CREATE TABLE import_declarations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    shipment_id UUID NOT NULL REFERENCES shipments(id),
    country_id UUID NOT NULL REFERENCES countries(id),
    importer_of_record VARCHAR(255) NOT NULL,
    declaration_number VARCHAR(100),
    declared_value NUMERIC(14,2) NOT NULL,
    declared_currency CHAR(3) NOT NULL,
    duty_paid NUMERIC(14,2),
    import_vat_paid NUMERIC(14,2),
    status VARCHAR(30) NOT NULL,
    documents JSONB NOT NULL DEFAULT '[]',
```

## 4. Financial integrity rules (mandatory)

1. No `float`/`double` for money anywhere (DB, PHP, TypeScript display logic).
2. Completed financial transactions are never deleted or edited; corrections are new rows.
3. Every refund references a payment (`refunds.payment_id NOT NULL`).
4. Sum of succeeded refunds per payment ≤ captured amount. Enforced in a transaction that
   locks the payment row (`SELECT … FOR UPDATE`), plus the `CHECK` on `refunded_amount`.
5. The exchange rate used at payment and at purchase is stored on the order item and supplier order.
6. Product price updates never change existing orders (snapshots).
7. One purchase per supplier order: unique `idempotency_key`, unique `(order_id, supplier_id)`,
   status check under row lock.
8. Order creation and splitting run in database transactions.
9. Order events are published through the outbox in the same transaction as the state change.
